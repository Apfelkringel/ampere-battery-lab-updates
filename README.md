# Ampere Battery Lab updates

This repository contains public release binaries and the update manifest for Ampere Battery Lab.
The application source code and user data are not stored here.

The current manifest points to release 0.59.

Release 0.59 makes automatic-backup status visible in the app and immediately notifies Android after a health-baseline change. The APK is the only executable artifact; source code, signing keys and user data are not stored in this repository.
