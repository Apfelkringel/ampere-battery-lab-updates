# Ampere Battery Lab updates

This repository contains public release binaries and the update manifest for Ampere Battery Lab.
The application source code and user data are not stored here.

The current manifest points to release 0.101.

Release 0.100 adds outside-tap and visible-X dismissal for Settings and blocks overlapping update checks, downloads and installer launches. Release 0.101 keeps the colored card rails inside the same rounded shape as their cards and keeps live mA values inside their status surface.

Release 0.60 separates detailed telemetry from automatic Android backup, validates imported keys before restore, neutralizes spreadsheet formulas in CSV exports, and bounds update metadata/download verification. Release 0.61 completes the manual backup allowlist for sleep-time statistics. Release 0.62 fixes the Light theme selection in Settings. Release 0.63 restores DownloadManager completion delivery using Android's signature-protected sender permission. Release 0.64 opens a selected history session in its matching charging or discharging view. Release 0.65 includes local telemetry in encrypted Android backups so data can survive a reinstall when the device backup transport is enabled. Release 0.66 aligns the in-app privacy and backup explanations with that encrypted-backup behavior. Release 0.67 makes the charger state display read-only and Android-derived. Release 0.68 avoids treating a full but unplugged battery as connected. Release 0.69 labels the design-capacity fallback explicitly when Android does not expose the factory value. Release 0.70 shows the correct sign for charging and discharging current in the overview and overlay. Release 0.71 makes the 7/30-day chart use real local telemetry windows and time-axis labels. Release 0.72 counts local screen wake events per discharge phase as a transparent deep-sleep wakeup proxy. Release 0.73 includes that wakeup metric in session details and analysis exports. Release 0.74 republishes the signed build with the complete wakeup export flow. Release 0.75 adds throttled background update notifications from the monitor service. Release 0.76 fixes the local discharging-current chart to display signed telemetry correctly. Release 0.77 restarts the background monitor after an app update. Release 0.78 clarifies that charger detection is automatic and read-only. Release 0.79 measures actual Android suspend time for discharge deep sleep. Release 0.80 handles power-connected and power-disconnected broadcasts immediately for more reliable session boundaries and charge alarms. Release 0.86 gives the native dashboard a complete visual redesign with clearer hierarchy, status chips, chart scales, rounded surfaces and pressed-state feedback. Release 0.87 makes the UI responsive across phone widths with safe-edge text fitting, compact navigation and stacked small cards. Release 0.89 centers the readable content width on wide displays such as tablets and foldables, while keeping touch coordinates aligned. Release 0.90 stabilizes charging/discharging sessions against transient cable/status broadcasts, suppresses zero-change history entries, and verifies the pinned release certificate, hash, package name and version before installation. Release 0.91 removes legacy zero-signal sessions from the visible history on load. Release 0.92 exposes the installed version directly in the header so an update can be verified on-device. Release 0.93 removes every 0-% history session, preserves genuine charge energy totals, and refreshes the native dashboard surfaces and active navigation state. Release 0.94 moves manifest lookup to the fixed GitHub Contents API path with raw-content response handling, avoiding stale Raw-CDN manifest responses while keeping the signed APK verification chain. Release 0.95 hardens the start page for compact, medium, wide and landscape windows: text uses the active centered column, the body is clipped to its content bounds, header controls adapt below 390 dp, display-cutout insets are included, and the hero surface stays bounded on wide screens. Release 0.96 adds a compact wide-landscape composition using a two-column live dashboard so the key state and metrics remain visible together on short windows, with the chart continuing in the same scroll flow. The APK is the only executable artifact; source code, signing keys and user data are not stored in this repository.
